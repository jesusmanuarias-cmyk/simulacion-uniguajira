# Simulación del campus de Uniguajira

Proyecto de Unity para simular el recorrido y la ocupación de puestos del campus.

1. Clona con Git LFS instalado y ejecuta `git lfs pull`.
2. Abre el proyecto con Unity **6000.6.9f1** desde Unity Hub.
3. Abre la escena `Assets/Simulation/Universidad.unity` y pulsa **Play**.
4. Usa **Iniciar lunes** para la simulación, **Prueba por edificio** para revisar un edificio o **Simulación → Universidad → Probar aforo máximo** para la prueba completa.

El mapa preparado para Unity y la NavMesh están incluidos. En el editor, las pruebas guardan sus CSV en `Documentation`.
